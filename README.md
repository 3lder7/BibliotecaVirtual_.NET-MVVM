# Biblioteca Virtual 📚
Um sistema de gerenciamento de biblioteca virtual desenvolvido em .NET utilizando o padrão arquitetural MVVM (Model-View-ViewModel).
Este projeto é uma aplicação desktop para gerenciamento de uma biblioteca virtual, permitindo o controle de livros, como cadastro, listagem, edição e remoção.

## 📁 Estrutura do Projeto
O projeto é composto pelos seguintes arquivos principais:
BibliotecaVirtual/
- Models/            (Classes de domínio)
- Views/             (Interfaces XAML)
- ViewModels/        (Lógica de apresentação)
- Services/          (Serviços e regras de negócio)
- Data/              (Camada de acesso a dados)
- Utils/             (Classes auxiliares)

## 🎯 Funcionalidades

- Cadastro de livros
- Listagem de livros
- Edição de livros
- Remoção de livros

## 🔧 Pré-requisitos

- .NET Framework 4.7.2 ou superior / .NET Core 3.1+
- Visual Studio 2019 ou superior
